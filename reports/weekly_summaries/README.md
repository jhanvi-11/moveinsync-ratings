# Weekly Summaries Directory

This directory stores automated weekly cohort intelligence digests generated by `src/summary.py`.

## File Naming Convention
Files are named according to their ISO weekly cohort:
- `YYYY-WW.md` (e.g. `2026-W41.md`)

Each digest contains:
1. Executive KPI Summary (Total volume, Mean star rating, WoW changes, Net Sentiment Score)
2. Taxonomy Breakdown & Sentiment Share table
3. Top Friction Subcategories table
4. Safety & Critical Escalations list
5. Recommended Operational & Product Actions
